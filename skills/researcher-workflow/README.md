# researcher-workflow Bundle

Generated by workflow-architect on 2026-05-31 and remediated for the Hermes built-in retrieval path.

This bundle encodes the researcher subagent's workflow: a non-interactive deep research pipeline that takes an orchestrator's mission brief and produces a progressive disclosure artifact pyramid.

## Skills

| Skill | Trigger | When it fires |
|-------|---------|---------------|
| receive-mission | Orchestrator assigns a research brief | Entry point — reformulates brief into structured scope and resolves a work root |
| research-gather | After scope is defined | Discovers with `web_search`, retrieves with `web_extract`, and records source evidence |
| evaluate-gaps | After initial gather | Applies three-question model, decides recursion |
| build-pyramid | After saturation reached | Assembles layered artifact files in the resolved work root |
| deliver-findings | After pyramid built | Reports paths back to orchestrator with layer descriptions |

## Loading

The bundle is loaded automatically when the researcher profile is dispatched. To load a specific sub-skill: `skill_view(name='researcher-workflow/<skill-name>')`.

Load `grounded-citations` for source-backed deliverables.

## Key Principles

- **Built-in retrieval first.** Use `web_search` for discovery and `web_extract` for selected pages and documents.
- **Conditional browser fallback.** Use browser automation only when normal extraction fails or interaction is required.
- **Progressive disclosure.** Each layer of the pyramid links downward with descriptions.
- **Three-question gap model.** In-scope? Changes conclusions? Depth or bulk?
- **Durable workspace.** Use the assigned Kanban workspace or current project for durable artifacts; reserve a Windows-safe temporary directory for explicitly ephemeral direct tasks.
- **Grounded handoffs.** Include source URLs and concise evidence, not raw research dumps.
